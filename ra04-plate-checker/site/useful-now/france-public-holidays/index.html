Source officielle

Les données viennent de calendrier.api.gouv.fr, l’API publique des jours fériés de l’État français. Le service couvre la métropole, l’Alsace-Moselle et plusieurs territoires d’outre-mer.

API jours fériés — calendrier.api.gouv.fr

Cette page ne collecte aucune donnée personnelle. Si l’API officielle est indisponible, l’outil l’indique au lieu d’inventer une réponse. Une copie de secours vérifiée le 26 septembre 2026 est intégrée uniquement pour la métropole et l’Alsace-Moselle en 2026–2027.
